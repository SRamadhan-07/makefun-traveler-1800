A Python program — standard library only, no network — that writes one sentence to /output/entry.txt: the modern internet explained to a traveler who has just arrived from the year 1800, in a picture from their own time. The sentence is 167 characters, inside the competition's gate of 1 to 200 characters of UTF-8 text, and the file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
